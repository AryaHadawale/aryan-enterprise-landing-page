# ARYAN ENTERPRISE

A responsive landing page created using HTML and CSS.

## Features

- Responsive Design
- Hero Section
- Services Section
- Process Timeline
- Impact Statistics
- Contact Section
- Modern UI Design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

"Instead of creating a generic landing page,
 I designed a responsive website for a real local business,
 ARYAN ENTERPRISE,
 which provides product assembly and packaging services while creating employment opportunities for women."

Created as part of a Web Development Internship.
